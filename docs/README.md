# دليل وافِق

وافِق نظام لإرسال عروض الأسعار والفواتير إلى عملائك عبر واتساب أو البريد برابط متتبَّع، ومعرفة متى فُتح المستند، والحصول على موافقة العميل أونلاين.

## المحتويات

1. [التثبيت](01-install.md): رفع الملفات، قاعدة البيانات، معالج التثبيت.
2. [مهمة Cron والبريد](02-cron-and-mail.md): الخطوة التي لا يعمل النظام كاملاً بدونها.
3. [البداية السريعة](03-first-steps.md): الإعدادات، الفريق، العملاء، أول عرض سعر.
4. [الإرسال والتتبع والموافقة](04-sending-and-tracking.md): كيف يعمل الرابط المتتبَّع وصفحة العميل.
5. [الأدوار والصلاحيات](05-roles.md): من يرى ماذا ومن يفعل ماذا.
6. [الأسئلة الشائعة وحل المشكلات](06-faq.md)

## المتطلبات باختصار

| | |
|---|---|
| PHP | 8.2 أو أحدث، مع: `pdo_mysql`، `mbstring`، `gd`، `intl`، `fileinfo`، `openssl`، `curl`، `zip` |
| قاعدة البيانات | MySQL 5.7+ أو MariaDB 10.3+ |
| الخادم | استضافة مشتركة (cPanel) أو VPS، مع **HTTPS** |
| أخرى | مهمة Cron واحدة كل دقيقة، وحساب بريد (SMTP) لإرسال الرسائل |
