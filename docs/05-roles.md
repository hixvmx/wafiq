# الأدوار والصلاحيات

لكل عضو دور واحد. يغيّره المالك أو المدير من صفحة **الفريق**.

| الصلاحية | المالك | مدير | محاسب | مبيعات | مشاهد |
|---|:-:|:-:|:-:|:-:|:-:|
| الإعدادات والهوية والترقيم والضرائب | ✓ | ✓ | — | — | — |
| دعوة الأعضاء وتغيير الأدوار وإزالتهم | ✓ | ✓ | — | — | — |
| إنشاء عروض الأسعار وتعديلها وإرسالها | ✓ | ✓ | ✓ | عروضه فقط | — |
| إنشاء الفواتير وتعديلها وإرسالها | ✓ | ✓ | ✓ | من عروضه الموافَق عليها فقط | — |
| رؤية كل المستندات والتتبع | ✓ | ✓ | ✓ | مستنداته فقط | ✓ |
| إضافة العملاء وتعديلهم | ✓ | ✓ | ✓ | ✓ | — |
| المنتجات والخدمات وأسعارها | ✓ | ✓ | ✓ | — | — |
| حذف المستندات | ✓ | ✓ | المسودات فقط | مسوداته فقط | — |
| التعليق والإشارة (@) | ✓ | ✓ | ✓ | على مستنداته | ✓ |

- **المالك** واحد فقط، يُنشأ أثناء التثبيت، ولا يمكن إزالته أو تغيير دوره.
- لا يستطيع أي عضو تغيير دوره أو إزالة نفسه.
- إزالة عضو لا تحذف المستندات التي أنشأها.
- الدخول برابط يصل إلى البريد (لا توجد كلمات مرور). الرابط صالح 15 دقيقة ولمرة واحدة.
