# التثبيت

يستغرق التثبيت قرابة 10 دقائق. لا تحتاج إلى أي أمر في الطرفية (Terminal): كل شيء من لوحة الاستضافة والمتصفح.

## 1. أنشئ قاعدة بيانات

من **cPanel ← MySQL Databases**:

1. أنشئ قاعدة بيانات جديدة (مثلاً `user_wafiq`).
2. أنشئ مستخدماً بكلمة مرور قوية.
3. أضف المستخدم إلى القاعدة مع **ALL PRIVILEGES**.

احتفظ بالأسماء الثلاثة وكلمة المرور، ستحتاجها بعد قليل.

> يجب أن تكون قاعدة البيانات **فارغة**. إن كانت فيها جداول من برنامج آخر سيرفض المعالج المتابعة.

## 2. ارفع الملفات

1. من **cPanel ← File Manager** ارفع الملف `wafiq-x.y.z.zip` إلى مجلد خارج `public_html` (مثلاً `/home/user/wafiq`)، ثم فك الضغط.
2. اجعل النطاق (أو النطاق الفرعي مثل `quotes.yourcompany.com`) يشير إلى المجلد **`wafiq/public`**:
   - نطاق فرعي جديد: **cPanel ← Domains ← Create A New Domain**، واكتب في Document Root المسار `wafiq/public`.
   - إن كان لا بد من استخدام `public_html`: انقل محتوى `wafiq/public` إلى `public_html`، ثم عدّل السطرين في `public_html/index.php` اللذين يذكران `__DIR__.'/../` ليشيرا إلى مجلد `wafiq`.
3. فعّل **HTTPS** للنطاق (cPanel ← SSL/TLS Status ← Run AutoSSL). الروابط التي ترسلها لعملائك يجب أن تكون آمنة.

## 3. شغّل معالج التثبيت

افتح النطاق في المتصفح. ستنتقل تلقائياً إلى `/install`:

| الخطوة | ماذا تفعل |
|---|---|
| **المتطلبات** | يفحص المعالج نسخة PHP والإضافات وصلاحيات الكتابة. إن ظهر عنصر أحمر فعّله من **cPanel ← Select PHP Version** ثم اضغط «إعادة الفحص». |
| **قاعدة البيانات** | أدخل بيانات الخطوة 1. ينشئ المعالج الجداول تلقائياً. |
| **الشركة والمالك** | اسم شركتك، العملة الأساسية، اسمك وبريدك. هذا البريد هو ما تدخل به (لا توجد كلمة مرور). |
| **البريد** | بيانات SMTP لحساب بريد على نطاقك، ويرسل المعالج رسالة تجريبية إليك. يمكنك التخطي والضبط لاحقاً. |
| **تم** | يعرض لك سطر Cron لنسخه (انظر [مهمة Cron والبريد](02-cron-and-mail.md))، ثم يدخلك إلى النظام. |

بعد انتهاء التثبيت يُغلق المعالج نهائياً ولا يمكن لأحد تشغيله مرة أخرى.

> إن تعطلت خطوة ما يمكنك الضغط على «البدء من جديد» أسفل المعالج.

## التثبيت على VPS (اختياري)

نفس الخطوات: وجّه الـ root في Nginx أو Apache إلى `public/`، واجعل مجلدي `storage` و`bootstrap/cache` قابلين للكتابة لمستخدم خادم الويب (`chown -R www-data storage bootstrap/cache`)، ثم افتح النطاق لتبدأ المعالج.
